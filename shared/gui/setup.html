Checking…

The installer printed a setup code. To see it again, run this in a terminal on this machine:

sudo agenti setup-code

Lowercase letters, digits, - or _. You'll use it to sign in.

Setup works only in a browser on the Agenti machine itself, so nobody else on the network can claim it first.

On that machine, open:

http://127.0.0.1:8420

From another computer, forward the port over SSH first, then open the same address here:

ssh -L 8420:127.0.0.1:8420 <the Agenti machine>

Or set up in the machine's terminal instead:

sudo agenti setup

Your account is ready. Two optional steps; both can be done later in Settings → Platform.

Anthropic API key

Encrypt the data (vault)
