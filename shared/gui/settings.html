Turn on the vault

      

      
Everything in Agenti's data folder is copied into a new encrypted container, checked, and the unencrypted original is deleted.

      
    
        
  • There is no recovery if the passphrase is lost. Not even an admin can get the data back.
    • 
        
  • After every restart of the server, someone must unlock it at the server's terminal: sudo agenti vault unlock. Until then nobody can start an agent or read a report (signing in still works).
    • 
        
  • No run may be going while it is turned on. It takes a few minutes.
