AI providers

          
Connect the AI services agents run on. Whoever launches a run picks one of them. Keys are kept on this server, used only by runs and never shown again.

          

          

            Keys for one person or one agent
            
A key saved here is the organisation's. A person or a single agent can have its own key instead; set those on the server: sudo agenti admin set-user-key <user> --provider openai or sudo agenti <agent> set-key --provider openai (or anthropic, local). Which models runs may use is set in Engagement.

Turn on the vault

      

      
Everything in Agenti's data folder is copied into a new encrypted container, checked, and the unencrypted original is deleted.

      
    
        
  • There is no recovery if the passphrase is lost. Not even an admin can get the data back.
    • 
        
  • After every restart of the server, someone must unlock it at the server's terminal: sudo agenti vault unlock. Until then nobody can start an agent or read a report (signing in still works).
    • 
        
  • No run may be going while it is turned on. It takes a few minutes.
