# Teams

A team is two or more agents working on one project, with a shared group chat
you can read and join. Each agent still runs its own tools inside its own scope.
A team changes how the agents talk to each other, never what any one of them
may do.

## Starting a team

On **Launch**, switch to **Team**, tick the agents, and give each its target. A
**Focus** is optional ("find out who owns the domain"): it's a hint about what
that agent should concentrate on. The model and limits are shared by the whole
team.

## What each agent knows

When a team starts, every agent is told:

- who it is on the project and what its own job is;
- who its teammates are, what each one does, and what each is pointed at;
- how to work as a team: introduce itself first, tell a teammate whenever it
  finds something they could use, ask the right teammate when it has a question,
  answer questions it is asked, and say when its own part is done.

A teammate's message reaches an agent **after its next step**, not only when its
whole task is over, so a question gets an answer while the work is still going.

## Reading the group chat

- Your messages are on the right; each agent has its own colour.
- **→ name** means the message is addressed to one teammate. Everyone can still
  read it.
- A card at the top lists who is on the project and what each is doing.
- When an agent says the project is complete, a green card shows its summary.
- **Show each agent's work** (off by default) also shows what each agent said to
  itself and how many steps it took, between the messages.

**Send** reaches every agent after its next step. **Note** is kept in the
record and the team document but never shown to an agent. **Attach** gives
every member the same file (see [Attaching files](attaching-files.md)). Nothing you or an
agent writes can widen any agent's scope or tools.

## Finishing

An agent that has finished its part votes the project complete, with a short
summary, then waits in case a teammate has a question. The project is complete
when every agent has agreed, or has ended. A new message after a vote asks that
agent to reconsider. **Mark complete** stops anything still running and moves
the project to Task History.

## The team document

**Open the team document** gives one readable account of the project: a short
summary, who did what, what each agent found, and how the team worked together
(introductions, questions, answers, who said the project was done and why). It
is assembled from what the agents actually said and wrote. No AI writes it. Each
agent's complete report, with every command and page, stays on that agent's own
page. Save it as PDF or download it as a Word file from the same page.

## If something looks wrong

| You see | What it means | What to do |
|---|---|---|
| *The agents never talked.* | An agent only speaks when it has something to share. Two agents on unrelated targets may have little to say. | Send a message to the team suggesting what to compare. |
| *An agent says "Understood" and nothing else.* | It acknowledged a message after finishing. Its findings are kept in its report. | Nothing. |
| *The project won't complete.* | An agent is still working, or has not voted. | Open the member's page, or use **Mark complete**. |
| *Back goes to "Team".* | You opened the agent from its team. | Use **Team** to return to the chat. |
